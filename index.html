In Lumber Tycoon 2, there is a large underground maze located under the Tropics biome. If you complete the maze, you can get to the cavecrawler wood. Every 4 days, the maze changes the path to cavecrawler wood.
With this tool you can find the working path leading to cavecrawler wood.
Note: The path is decided during server creation. On older servers, the current path may not work—use the arrow buttons above to view previous paths.
